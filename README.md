# Roomwise

Калькулятор стоимости проживания для администраторов **Turan Resort** — сезонного курортного отеля.
Администратор вводит параметры брони (категория номера, гости, даты), а приложение считает сумму
по ценовым периодам сезона и формирует готовый текст для клиента.

Приложение полностью работает **на устройстве, без сервера**: расчёты, настройки цен и история
хранятся локально. Интернет нужен только для необязательного ИИ-разбора сообщений клиентов.

> Ранее проект назывался *Turan Resort Admin Price Calculator* и работал как FastAPI-сервер в локальной сети.
> Эта версия сохранена в [`legacy/server/`](legacy/server) как справочная — см. [раздел ниже](#legacy-python-сервер).

## Возможности

| Экран | Файл | Что делает |
|---|---|---|
| **Расчёт** | `index.html` | Форма брони → итоговая сумма, скидка, предоплата, разбивка по периодам и текст для клиента (копируется одной кнопкой). Каждый расчёт автоматически сохраняется в историю. |
| **История** | `history.html` | Все расчёты, сгруппированные по дням, с ленивой подгрузкой, фильтром по датам, подробной разбивкой, удалением свайпом и загрузкой обратно в калькулятор. |
| **ИИ** | `parse.html` | Вставляете сообщение клиента (RU / EN / KZ) → Google Gemini извлекает параметры брони → расчёт выполняется локально. |
| **Цены** | `settings.html` | Редактор категорий, ценовых периодов, цены питания и таблицы цен. Изменения сохраняются автоматически. |
| **API** | `api-key.html` | Ввод / удаление ключа Gemini. |

### Правила расчёта

- Сезон делится на **ценовые периоды** (например, 15.06–21.06, 22.06–03.07 …). Проживание разбивается на
  сегменты по периодам, каждая ночь считается по цене своего периода.
- Все цены указываются **с питанием**. Для гостей без питания из цены за ночь вычитается `meal_price`.
- **Категории** задают допустимую вместимость номера, разрешены ли доп. места и размер скидки для гостей с ОВ.
- **Гости с ОВ** (ограниченными возможностями) получают фиксированную скидку за ночь, заданную в категории.
- **Доп. места** доступны только в категориях с `allow_extra_beds` и имеют свою цену.
- Итог: `сумма → скидка % → итого со скидкой → предоплата %`.
- ИИ только извлекает данные из текста и **никогда не считает деньги**. Гости от 14 лет считаются взрослыми.

### Как устроен «серверless»-режим

Экраны изначально писались под FastAPI-бэкенд и обращаются к `fetch('/api/...')`.
Вместо сервера на каждой странице подключается `local-api.js`, который перехватывает эти запросы и
отвечает теми же JSON-структурами, используя локальные модули:

```
app.js / parse.js / admin.js / api-key.js
        │  fetch('/api/calc' | '/api/parse' | '/api/admin/prices' | …)
        ▼
local-api.js ──► pricing-engine.js   (расчёт)
             ──► local-store.js      (цены и ключ → localStorage)
             ──► local-parse.js      (Gemini, только онлайн)
```

Поэтому порядок подключения скриптов важен: `pricing-engine.js` → `local-store.js` → `local-parse.js`
→ `local-api.js` → остальные.

### Где хранятся данные

| Данные | Хранилище | Ключ |
|---|---|---|
| Конфиг цен | `localStorage` | `roomwise_pricing` (если пусто — `DEFAULT_CONFIG` из `local-store.js`) |
| Ключ Gemini | `localStorage` | `roomwise_gemini_key` |
| История расчётов | IndexedDB | БД `roomwise`, хранилище `calculations` |

Данные живут только на конкретном устройстве и удаляются вместе с данными приложения / браузера.

## Запуск для разработки

Нужен любой статический HTTP-сервер (IndexedDB не работает при открытии файла через `file://`).

```bash
npm run dev
```

Откройте <http://localhost:8080>. Команда эквивалентна `py -m http.server 8080 --directory static`.

Калькулятор можно открыть с предзаполненной формой через параметры URL, например:
`index.html?category=standard&room_size=3&adults_meal=2&check_in=2026-07-05&check_out=2026-07-10`.

## Сборка Android-приложения (APK)

**Требуется:** Node.js, Android Studio (Android SDK, API 34), JDK 17.

1. Установить зависимости (один раз):

   ```bash
   npm install
   ```

2. Скопировать актуальный `static/` в Android-проект — **после каждого изменения веб-кода**:

   ```bash
   npm run sync
   ```

3. Собрать APK — либо из Android Studio:

   ```bash
   npm run open:android
   ```

   либо из командной строки:

   ```bash
   npm run build:apk
   ```

   Готовый файл: `android/app/build/outputs/apk/debug/app-debug.apk`.

Параметры приложения: `appId` — `com.roomwise.app`, `minSdk` 22, `targetSdk` 34 (см. `android/variables.gradle`).

## Настройка

### Цены

Цены редактируются прямо в приложении на экране **«Цены»** и сохраняются на устройстве.

Чтобы поменять цены **по умолчанию** (для новых установок), отредактируйте `DEFAULT_CONFIG`
в `static/local-store.js`. На устройствах, где цены уже сохранялись, по-прежнему будет использоваться
локальная копия.

Формат конфига:

```jsonc
{
  "constants":  { "meal_price": 7000 },                        // стоимость питания за ночь
  "periods":    [{ "id": "p1", "start": "06-15", "end": "06-21" }],   // ММ-ДД, включительно
  "categories": [{ "id": "comfort", "label": "Комфорт",
                   "room_sizes": [2, 3], "allow_extra_beds": true, "disabled_discount": 3000 }],
  "prices": {
    "comfort": {
      "adult":     { "p1": 16000 },   // цена за ночь с питанием
      "child":     { "p1": 14000 },
      "extra_bed": { "p1": 15000 }    // только для allow_extra_beds: true
    }
  }
}
```

### ИИ-разбор сообщений (необязательно)

1. Получите ключ в [Google AI Studio](https://aistudio.google.com/apikey).
2. Введите его на экране **«API»**.
3. На экране **«ИИ»** вставьте сообщение клиента и нажмите «Разобрать».

Запрос идёт напрямую с устройства в Gemini API (модели `gemini-2.5-flash` → `gemini-2.0-flash` →
`gemini-2.5-flash-lite` по очереди). Без ключа или интернета остальные функции работают как обычно.

## Legacy: Python-сервер

Папка [`legacy/server/`](legacy/server) содержит первую версию приложения: FastAPI-сервер для локальной
сети и сборку Windows-установщика. **В работе не участвует** и сохранена как эталон логики:
`static/pricing-engine.js` — точный порт `pricing.py`, `static/local-parse.js` — порт `parse.py`.

| Файл | Назначение |
|---|---|
| `main.py` | FastAPI-приложение, API `/api/*` |
| `pricing.py`, `models.py` | Движок расчёта и Pydantic-модели |
| `parse.py` | ИИ-разбор через `google-genai` |
| `prices.json` | Конфиг цен (совпадает с `DEFAULT_CONFIG`) |
| `requirements.txt` | Python-зависимости |
| `TuranResortAdmin.spec`, `main.spec` | Сборка `.exe` через PyInstaller |
| `TuranResortAdmin.iss`, `build_installer.bat` | Установщик Inno Setup |

> ⚠️ Текущие страницы в `static/` используют относительные ссылки (`history.html`, `ds.css`),
> которые старый сервер не отдаёт, — для работы с ним фронтенд пришлось бы адаптировать.
> Кроме того, `main.spec` упаковывает `gemini_api_key.txt` внутрь сборки — не распространяйте такой `.exe`.

Запуск (для справки):

```bash
cd legacy/server
pip install -r requirements.txt
py main.py
```
